# HotelPro feature captures

The feature walkthrough is `HotelPro_Feature_Walkthrough.webm` at 3840 × 2160 (4K UHD). `HotelPro_Feature_Walkthrough_1600x1000.webm` preserves the screenshots' native resolution.

The 4K version is upscaled from 1600 × 1000 screenshots, so it provides a 4K video frame without adding detail beyond the original captures.

The 21 screenshots cover the landing page, room collection and details, account creation and sign-in, guest dashboard and reservations, guest service requests, staff dashboard/front desk/service queue/room status, and admin dashboard/bookings/services/inventory/add room/payments/reports/team/activity log.

The demo captures use local sample records for presentation. They do not represent a live database or change real bookings or payments.
